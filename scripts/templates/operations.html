    To download new imagery, create Copernicus Data Space service credentials and set both environment variables before starting the server. The bundled example works without them.

    Linux and Windows setup instructions

    Use the client ID and secret from your Copernicus Data Space account. Replace the example values locally.

    Linux (bash):

    export CDSE_CLIENT_ID='your-client-id'
export CDSE_CLIENT_SECRET='your-client-secret'

    Windows (PowerShell):

    $env:CDSE_CLIENT_ID='your-client-id'
$env:CDSE_CLIENT_SECRET='your-client-secret'

    In the same terminal, restart the server for the same workspace:

    opendarksts stop
opendarksts serve

    For a custom workspace, include --workspace "path to workspace" before each command. Credentials are read at server startup and are not stored in the project settings.

    Sensitivity, AIS search radius & model

    Low = 0.10, Medium = 0.25 (default), High = 0.45. A lower threshold includes weaker predictions and may produce more false alarms. The default AIS search radius is 1,000 m. The safety filter discards boxes occupying more than half the tile area.

    Understanding AIS result labels

    These labels describe nearby AIS records on the same day. They do not identify the visible hulls or determine whether an activity is legal.

    FULLY_DARK
    No AIS vessels found within the search radius that day.
    PARTIALLY_DARK
    One AIS vessel found within the radius that day.
    AIS_PRESENT
    Two or more AIS vessels found within the radius that day.
    DETECTED_ONLY (stored as AIS_MISSING)
    Records were not supplied or are unavailable for that day. Vessel presence is unknown.
    AIS_ERROR (stored as AIS_INVALID)
    Records could not be read or verified. Vessel presence is unknown.
    NO_STS
    The completed scan found no candidate pairs.
